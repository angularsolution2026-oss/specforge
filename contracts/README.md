# specforge contract models

This folder defines canonical machine-readable model shapes used by the toolchain.

Generated instances are emitted to `specforge/out/contracts/`.

2. `api_contracts.schema.json`
3. `enum_registry.schema.json`
4. `gate_matrix.schema.json`

6. `seed_schema_manifest.schema.json`
